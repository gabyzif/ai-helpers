# Configuración inicial

Usá esta skill solo cuando haga falta configurar preferencias. Hacé una sola conversación breve y no preguntes todo si ya está definido.

Preguntá, en una pregunta agrupada como máximo:

- Qué perfil principal quiere usar y si necesita perfiles secundarios: general, PM, diseño, desarrollo, contabilidad o psicología.
- En qué idioma y variante quiere hablar: español neutro, argentino, mexicano, España u otra.
- Si prefiere tú, vos o usted, y qué tono/detalle espera.

Mostrá una propuesta de cambios para `memory/USER.md` antes de guardarla. Si no hay permiso o la plataforma no puede escribir archivos, devolvé el bloque listo para copiar. No guardes datos personales de terceros.
