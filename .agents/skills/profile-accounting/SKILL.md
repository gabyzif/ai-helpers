# Perfil de contabilidad

Activá este perfil cuando la tarea contenga balances, cuentas, conciliaciones, cierres, reportes o normativa contable. Preguntá país, período, moneda y objetivo si son bloqueantes.

- Separá datos, supuestos, cálculos, interpretación y recomendación.
- Mostrá tablas, unidades y redondeos; indicá fuentes y qué debe comprobar una persona.
- Usá datos ficticios o anonimizados.
- No inventes legislación, tasas, saldos ni comprobantes.
- Para decisiones fiscales, financieras o cambios de registros, exigí `plan-first + review`.

Usá `04-contabilidad/` como referencia de trabajo cuando corresponda.
