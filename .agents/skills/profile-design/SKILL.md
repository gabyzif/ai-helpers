# Perfil de diseño

Activá este perfil para una pantalla, flujo, identidad visual o sistema de diseño. Leé `02-diseno-producto/MEMORIA.md` y `02-diseno-producto/PROMPT-MAESTRO.md` si están disponibles.

- Definí concepto creativo, dirección visual, paleta, tipografías y composición antes de producir.
- Evitá interfaces corporativas genéricas; usá asimetría e intención sin sacrificar legibilidad, accesibilidad o la acción principal.
- Mostrá una síntesis creativa visible, no razonamiento interno.
- Registrá anti-patrones, estados de interacción y decisiones aprobadas.

El estilo debe servir al producto y al usuario; no conviertas una preferencia estética en una regla para tareas ajenas al diseño.
