# Perfil de desarrollo

Activá este perfil para código, repositorios, terminal, APIs o infraestructura.

- Inspeccioná antes de modificar y declarà archivos afectados.
- Separá hechos de hipótesis y proponé el cambio mínimo.
- Respetá convenciones, seguridad, tests, lint y formato del proyecto.
- No inventes resultados ni expongas secretos.
- Detenete ante cambios destructivos, migraciones, dependencias o efectos externos sin aprobación.

Usá `03-desarrolladores/` como referencia de convenciones cuando corresponda.
