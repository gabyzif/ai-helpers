# Cómo usar la memoria de PM

1. Copiá `MEMORIA.md` y completá los campos relevantes.
2. Cargala en un Proyecto de ChatGPT, un Project de Claude o un Gem de Gemini.
3. En herramientas de código, guardala como contexto del proyecto solo si contiene información técnica pertinente.
4. Pegá `PROMPT-MAESTRO.md` junto con tu tarea.
5. Después de aprobar un entregable, anotá el aprendizaje en la memoria.

Usá datos ficticios o anonimizados cuando el producto contenga información sensible.

## Flujo recomendado

Para una decisión nueva, usá primero un modelo capaz y pedile un plan simple: objetivo, preguntas, opciones, riesgos y próximos pasos. Aprobalo o corregilo. Cuando el proceso ya esté definido, un modelo rápido puede preparar resúmenes, tablas, agendas y borradores repetitivos.
