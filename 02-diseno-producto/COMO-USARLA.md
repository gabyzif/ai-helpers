# Cómo usar la memoria de diseño

1. Completá `MEMORIA.md` con identidad, estilos, paleta, tipografías y anti-patrones.
2. En cada plataforma, cargá la memoria en el espacio persistente indicado en `recursos-compartidos/PLATAFORMAS.md`.
3. Adjuntá referencias visuales y describí qué debe diseñarse.
4. Pegá `PROMPT-MAESTRO.md` y completá la sección `detalles_del_producto`.
5. Después de aprobar una dirección visual, agregá la decisión a `MEMORIA.md`.

Las capturas sirven como referencia visual, pero no reemplazan describir qué se aprobó: color, tipografía, composición, interacción y motivo.

## Flujo recomendado

Para una pantalla nueva, usá primero un modelo capaz para definir el concepto, la dirección visual y el plan de exploración. Aprobá esa dirección. Después podés usar un modelo rápido para generar variantes, adaptar tamaños o aplicar reglas ya aprobadas.
