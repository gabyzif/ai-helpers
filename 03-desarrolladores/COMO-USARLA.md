# Cómo usar la memoria de desarrollo

1. Completá `MEMORIA.md` sin incluir claves, tokens, datos de clientes ni archivos privados.
2. En un repositorio, guardala como `AGENTS.md` o referenciala desde el archivo de instrucciones de la plataforma.
3. Para una consulta puntual, cargala junto con `PROMPT-MAESTRO.md`.
4. Pedí primero un plan corto y la lista de archivos afectados.
5. Después de una solución verificada, registrá la convención o aprendizaje que convenga conservar.

## Flujo recomendado

Para un bug o feature importante, pedí primero un plan con archivos afectados, riesgos y pruebas. Revisalo antes de autorizar cambios. Para tareas mecánicas y bien definidas —formatear, renombrar o escribir tests similares— podés usar un modelo rápido. Volvé a uno capaz si cambia el diseño o aparece un error difícil.
