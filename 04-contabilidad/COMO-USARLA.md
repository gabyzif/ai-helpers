# Cómo usar la memoria de contabilidad

1. Completá solo jurisdicción, formato y preferencias de trabajo.
2. Reemplazá toda información real por nombres y números ficticios antes de cargar documentos.
3. Configurá la memoria en un Proyecto, Project o Gem según la plataforma.
4. Incluí período, moneda y objetivo en cada consulta.
5. Revisá cálculos y normativa con una persona competente antes de usar el resultado.

## Flujo recomendado

Para un análisis nuevo, usá un modelo capaz para ordenar supuestos, fuentes y riesgos. Pedile primero una lista de pasos y aprobala. Un modelo rápido sirve luego para ordenar datos ficticios, convertir formatos o preparar un borrador, siempre con revisión humana.
