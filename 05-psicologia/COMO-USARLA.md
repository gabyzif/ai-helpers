# Cómo usar la memoria de psicología

1. Completá enfoque, audiencia, tono y formato sin incluir historias clínicas.
2. Cargá la memoria en el Proyecto, Project o Gem correspondiente.
3. Usá casos ficticios o anonimizados para pedir borradores.
4. Revisá precisión, lenguaje, sesgos, privacidad y adecuación profesional.
5. Registrá aprendizajes solo como reglas generales, nunca como datos de una persona.

## Flujo recomendado

Para crear un material nuevo, usá un modelo capaz para definir audiencia, objetivo, límites y posibles riesgos. Aprobá el esquema antes de redactar. Un modelo rápido puede ayudar a reformular, resumir o adaptar un material ya revisado; la revisión profesional sigue siendo necesaria.
