# Contribuir al proyecto

Activá esta skill solo cuando la persona quiera compartir una mejora.

1. Separá conocimiento personal de una mejora general. La memoria privada nunca se copia directamente.
2. Eliminá nombres, pacientes, clientes, cuentas, credenciales, rutas privadas, cifras identificables y contexto innecesario.
3. Clasificá el aporte: nuevo perfil, skill, workflow, mejora de prompt, adaptador, documentación, prueba o bug.
4. Buscá duplicados si hay una herramienta para hacerlo; si no, declaralo.
5. Prepará un Issue o PR con problema, propuesta, archivos, prueba reproducible, plataformas afectadas y riesgos.
6. Mostrá el contenido exacto que se publicaría y esperá aprobación. Sin aprobación, entregá solo un borrador local.

Para cambios en `dist/`, modificá primero las fuentes y regenerá los paquetes. No incluyas archivos personales en un PR.
